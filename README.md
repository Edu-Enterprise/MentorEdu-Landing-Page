# MentorEdu Landing Page

Landing page v2 para MentorEdu, actualizada al nuevo concepto del proyecto:
repositorio colaborativo de exámenes de admisión, foros por pregunta,
gamificación y moderación para el ecosistema preuniversitario peruano.
